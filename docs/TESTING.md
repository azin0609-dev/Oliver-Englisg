# 驗收與限制

本紀錄區分程式測試、桌面瀏覽器的行動模擬，以及真正 iPhone 的待測項目，不把模擬結果當作真機通過。

## 執行環境

- Node.js 24.22.1、npm 11.9.0。
- TypeScript 5.9、React 19、Vite 7、Vitest、Playwright。
- 系統 Chromium；Playwright iPhone 13 裝置參數與 320、375、390、768px 視窗。
- 測試針對 `npm run build` 的正式產物，包含實際 Service Worker；未使用開發伺服器冒充離線驗證。
- 語音測試使用可觀察的 Web Speech API 替身，驗證呼叫順序、語速、聲音選擇與取消；不代表任何真實裝置的聽感。

初次離線測試發現靜態伺服器的 `Vary: Origin` 會使模組資源錯過預快取。已在限定為同源、列入建置清單的公開 App 資源中使用 `ignoreVary` 修正，並通過離線重開驗證。沒有擴大快取到外部網站或個人資料。

## iPhone 真機驗收清單（尚未執行）

建議使用部署後的 HTTPS 網址，在至少一台實體 iPhone 的 Safari 與加入主畫面的 App 各做一次：

1. 查看 iOS 版本，記下 Safari 與 PWA 的差異。
2. 點正常／慢速／下一個句子／停止，確認沒有重疊或卡住；回到前景仍能重新點擊播放。
3. 切換美式與其他英文聲音，確認設定保留。下載一個裝置語音，斷網後測發音；聲音品質由系統決定。
4. 首次連網等待「教材已備妥，可離線使用」，關閉 App、開飛航模式再啟動，進入不同情境及收藏。
5. 離線修改程度與收藏，關閉重開，確認資料存在。
6. 主畫面啟動應沒有網址列；檢查瀏海、底部 Home Indicator 與橫直切換，不遮住教材或按鈕。
7. 匯出 JSON 到「檔案」，再從「檔案」選檔匯入，驗證預覽與取消。
8. 比較 Safari 與主畫面 App 的資料是否共用；若不共用，用 JSON 手動移轉，不聲稱已有同步。
9. 發布新版後，回到前景檢查更新提示，點更新後確認原有紀錄保留。
10. 用 VoiceOver 與 iOS 較大文字檢查可操作性；目前未進行完整無障礙認證。

## 尚未驗證／不在本版範圍

- 真機 iPhone Safari、主畫面模式、各 iOS 聲音的音訊輸出。
- 正式主機上的實際部署、HTTPS、安全標頭與 CDN 快取政策。
- 真人幼教教師與家長的教材／可用性審查。
- 帳號、後端、跨裝置同步、AI、錄音、訂閱與推播（依第一版需求排除）。
