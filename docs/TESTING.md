# 驗收與限制

本紀錄區分程式測試、桌面瀏覽器的行動模擬，以及真正 iPhone 的待測項目，不把模擬結果當作真機通過。

## 執行環境

- Node.js 24.22.1、npm 11.9.0。
- TypeScript 5.9、React 19、Vite 7、Vitest、Playwright。
- 系統 Chromium；Playwright iPhone 13 裝置參數與 320、375、390、768px 視窗。
- 測試針對 `npm run build` 的正式產物，包含實際 Service Worker；未使用開發伺服器冒充離線驗證。
- 語音測試使用可觀察的 Web Speech API 替身，驗證呼叫順序、語速、聲音選擇與取消；不代表任何真實裝置的聽感。

- 備份下載的內容正確；錯誤匯入不變更；確認前預覽；取消不變更；確認後重開保留。
- 真實正式版 SW 在連網時快取，再讓瀏覽器完全斷網，開新頁瀏覽未開過的睡前情境、收藏與儲存紀錄。
- 真實新版本 SW 等候家長按「更新 App」才切換，更新後保留紀錄、刪除舊 shell cache。
- 難度、課日變更後重開；裝置儲存寫入失敗會明確警告，尚未落盤的記憶體資料可匯出。
- 代表頁面在 320／375／390／768px 沒有水平溢位。

初次離線測試發現靜態伺服器的 `Vary: Origin` 會使模組資源錯過預快取。已在限定為同源、列入建置清單的公開 App 資源中使用 `ignoreVary` 修正，並通過離線重開驗證。沒有擴大快取到外部網站或個人資料。

## v1.1 新增驗收

- 舊版 localStorage 與 v1 JSON 備份升級後，收藏、程度、練習次數與歷史保留；新增欄位只補預設空陣列。
- v2 備份包含課堂及小發現筆記，可往返匯入；非法教材 ID、主題與欄位會被拒絕。
- 六個快捷情境一鍵開啟，有真實教材、動作與可結束的陪伴流程。
- 每日預設短活動，七項清單收在展開區，短活動完成後重開仍保留。
- 沉默、單字、中文與不想玩四種接話提示能切換；不錄音、不假裝翻譯孩子的話。
- 問候隨時間改變；暱稱出現在教材回應與搜尋欄位；品牌頁可從首頁進入。
- 課堂筆記保存、重開與編輯；老師選的近兩週句子進入下次短活動，不自動增加已學會程度。
- 小發現保存及編輯不重複新增，並可匯出備份。
- 語音名單排除 iOS 角色／趣味聲音，建議聲音優先；正常、慢速、停止與分段都呼叫同一個語音管理器。
- 品牌頁、快捷情境、課堂筆記也納入 320–768px 溢位檢查。

## Phase 0 新增驗收

- 首頁與主導覽沒有語音檢測入口；設定頁最底部的小字連結能開啟隱藏頁。
- 模擬 iOS 先回傳空清單，再發出 voiceschanged；全部聲音均出現，包含角色音與中文聲音，並顯示自動與實際選用聲音。
- 5 句生活句與 8 個困難名稱的正常／慢速共 26 個按鈕，確實交給既有語音管理器，以 0.96／0.82 語速播放完整文字；每次先 cancel，停止鍵可取消。
- 從已載入的設定頁進入與播放，不寫入 localStorage，也沒有新增應用程式請求。Chromium 在 Hash 導覽後可能重新取得既有 favicon；測試只排除此種瀏覽器圖示請求，fetch／XHR 及其他請求仍必須為零。
- 複製的純文字含 userAgent、全部聲音的四項欄位、自動與實際選擇、語速；不含孩子暱稱或練習資料，不寫入儲存空間。
- 空聲音清單、剪貼簿權限遭拒時提供明確回饋與可手動複製的文字。
- 只有線上系統語音時，不呼叫播放，避免檢測功能觸發系統語音的對外連線。
- 檢測頁在 320／390px 沒有水平溢位。

以上使用語音 API 替身，沒有冒充 iOS 真實聲音。內容盤點對照 112 個來源 ID，73 句 instruction／question 均附替代草稿；原教材未更動。完成後依使用者指令停在 Phase 0，真機操作見 [PHASE-0.md](PHASE-0.md)。

[語音檢測頁截圖](screenshots/voice-check-390.png) 使用 Chromium 390px 行動尺寸，呈現該瀏覽器實際回報的空聲音清單，並非 iPhone 真機結果。

## iPhone 真機驗收清單（尚未執行）

建議使用部署後的 HTTPS 網址，在至少一台實體 iPhone 的 Safari 與加入主畫面的 App 各做一次：

1. 查看 iOS 版本，記下 Safari 與 PWA 的差異。
2. 點正常／慢速／下一個句子／停止，確認沒有重疊或卡住；回到前景仍能重新點擊播放。
3. 切換美式與其他英文聲音，確認設定保留。下載一個裝置語音，斷網後測發音；聲音品質由系統決定。
4. 首次連網等待「教材已備妥，可離線使用」，關閉 App、開飛航模式再啟動，進入不同情境及收藏。
5. 離線修改程度與收藏，關閉重開，確認資料存在。
6. 主畫面啟動應沒有網址列；檢查瀏海、底部 Home Indicator 與橫直切換，不遮住教材或按鈕。
7. 匯出 JSON 到「檔案」，再從「檔案」選檔匯入，驗證預覽與取消。
8. 比較 Safari 與主畫面 App 的資料是否共用；若不共用，用 JSON 手動移轉，不聲稱已有同步。
9. 發布新版後，回到前景檢查更新提示，點更新後確認原有紀錄保留。
10. 用 VoiceOver 與 iOS 較大文字檢查可操作性；目前未進行完整無障礙認證。

## 尚未驗證／不在本版範圍

- 真機 iPhone Safari、主畫面模式、各 iOS 聲音的音訊輸出。
- 正式主機上的實際部署、HTTPS、安全標頭與 CDN 快取政策。
- 真人幼教教師與家長的教材／可用性審查。
- 帳號、後端、跨裝置同步、AI、錄音、訂閱與推播（依第一版需求排除）。
