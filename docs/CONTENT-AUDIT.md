## 分類方式與限制

- 以卡片的主要預期用途分類，不只看標點：要求找物品或執行動作的 Can you… 列為 instruction；詢問偏好、需求、位置或比較列為 question；Let's／Shall we 的共同活動列為 invitation；陳述狀態、觀察、需求列為 description；明確玩笑、唱念或故意說錯才列為 play。
- 孩子的求助示範也可能是 instruction 文法，孩子的求物句也可能是 question；這不等同「成人在命令／考孩子」。角色與情境需要一起讀。
- 招呼、感謝、祝福、複合句及只看文字無法判斷的共玩語氣標為 **uncertain**，不硬塞入五類。uncertain 是待審類別，不是語文錯誤，也不代表需要改寫。
- 指令與提問不等於不恰當。安全界線、身體舒適度、真正可選的選擇及徵求同意應保留。替代句示範另一種互動方式，不可機械取代必要的安全提醒。
- 目前沒有真人教師逐句簽核，也沒有這批句子的三歲家庭實測；不以字數或問號當作發展評量。

## 本階段結論與下一步

- 教材主句目前偏向指令與提問，但部分是在教孩子表達需要，不能只用比例判斷整個 App 的互動品質。
- 值得先試的方向是增加成人描述、一起做的邀請與不要求回覆的共玩；改寫仍要經人工審核，不能由盤點直接替換上線。
- 語音聽感、困難名稱是否念對，需使用 Phase 0 的 iPhone 語音檢測頁判斷。電腦測試不能證明名字發音正確。
- **依 docs/codex-v1.2.md，Phase 0 完成後停止。等待家長的語音檢測結果與後續明確指令，不進入 Phase 1。**
