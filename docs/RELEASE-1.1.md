# v1.1 · 一句日常，一點陪伴

給忙碌的 3–6 歲孩子爸媽：英文不用很厲害，也能把陪伴說成英文。

## 這次改變

1. **拿起來就用**：六個首頁快捷情境、最近練習過的句子、較清楚的播放按鈕與手機閱讀層級。
2. **接得下去**：孩子沒回答、只說單字、用中文或想停下來，都有可播放的接話靈感。以教材回答為例，家長依孩子實際意思換字，不進行錄音或即時翻譯。
3. **一小段就好**：每日先顯示一句與一個動作，想玩更多再展開完整五分鐘；小段完成後才出現選用的觀察記錄。
4. **課堂帶回家**：家長選主題與最多三句課堂英文，保存日期與筆記。近兩週的選句會優先安排在下一組推薦，也可成為當日短活動。保存筆記本身不把孩子標為已學會。
5. **記住生活**：成長頁先呈現小發現筆記，可編輯與備份；既有觀察摘要仍可展開。「尚未觀察」更準確表達家長尚無記錄的狀態。
6. **爸媽安心示範**：優先一般美式英文、排除角色音與趣味音效，維持自動選擇；語速調整為正常 0.96、慢速 0.82，另提供短語分段。來源仍是裝置系統聲音，未新增付費或外部語音 API。
7. **品牌說明**：首頁、選單、設定頁都有入口。文案聚焦忙碌家長如何利用生活建立美語情境，尊重孩子的步調，並保留隱私說明。

## 舊資料與備份

- 仍使用 `oliver-adventure-v1`，既有收藏、程度、次數、練習歷史及設定不重設。
- 新增的 `classSessions`、`memories` 若不存在，讀取時補上空陣列。
- 匯出備份格式升為 v2；新版仍可匯入原本的 v1 備份。
- 筆記仍保存在各自裝置，沒有新增帳號或跨裝置同步。新功能和學習紀錄都由家長自行匯出保管。
- 既有 PWA 會等待家長點「更新 App」才切換。更新不刪除 localStorage。

## 驗證與限制

TypeScript 嚴格檢查、36 項單元測試、21 項手機尺寸 Chromium 測試與正式建置；詳細證據見 [TESTING.md](TESTING.md)。截圖在 `docs/screenshots/`。

iPhone 真機的聲音聽感、裝置語音庫及 Safari／主畫面差異仍需實機驗收。程式能篩選已知特殊聲音與優先語音，不能保證不同裝置的音質一致。正式網站由 GitHub Pages 接收部署分支後處理發布；本環境的網路政策不允許直接開啟 `azin0609-dev.github.io`，因此無法在此證明線上網址已載入新版。
