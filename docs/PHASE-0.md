接話提示目前已有「先等一會兒」與接住中文意思的方向，但「等待約五秒」只明寫在 17 筆主句提示；中文分頁未直接寫出「不要求孩子用英文再說一次」。固定範例不能當作孩子實際中文的翻譯。

不確定之處包括：14 句的社交／遊戲／複合用途需要看真實語氣；`playpen` 是否符合家中道具；`Is it the same or different?` 的比較對象；部分長句是否符合孩子經驗。完整 ID、原句與理由都在報告中，沒有擅自判定英文錯誤。

## iPhone 語音驗收方式

沿用網址：<https://azin0609-dev.github.io/Oliver-Englisg/#/voice-check>。

1. 連網打開 App，若出現「更新 App」，先點更新。也可從設定頁最底部進入「語音檢測（進階）」。不要清除網站資料。
2. 查看「App 自動選擇」與「目前實際選用」，等待聲音清單載入。兩者可能因家長之前選過聲音而不同。
3. 播放 5 句生活句及 8 個困難名稱，分別聽正常與慢速；家長操作即可，不用請孩子跟念。
4. 按「複製檢測結果」，貼回對話，再補充哪個項目、哪種語速聽起來怪。無法自動複製時，可長按頁面提供的文字手動複製。
5. 最好用兩支不同 iOS 版本的 iPhone；若只有一支，先完成手邊裝置。Safari 與主畫面 App 若不同，也請註明。

檢測報告包含 userAgent、全部聲音的 name／lang／localService／default、自動與實際選用聲音、語速；不含孩子暱稱、收藏或學習紀錄。檢測頁不新增 fetch／XHR、上傳或儲存。App 本身初次載入、既有 SW 更新及瀏覽器載入圖示仍屬網站基礎載入。

為遵守本階段不新增對外請求的要求，檢測播放只允許瀏覽器回報 `localService=true` 的裝置語音。若目前選的是線上系統語音，頁面會停用播放並說明如何下載與選用裝置聲音；不會偷偷改掉家長設定。

## 自動化證據與限制

| 檢查         | 結果                                |
| ------------ | ----------------------------------- |
| TypeScript   | 通過                                |
| 單元測試     | 原有 36 項通過                      |
| 正式建置     | 通過；SW 快取包含 9 項本機資源      |
| 行動尺寸 E2E | 原有 21 項＋新增 5 項，共 26 項通過 |

E2E 使用 Chromium 的行動尺寸與語音 API 替身；驗證所有 26 個播放按鈕、語速、取消舊播放、無診斷資料寫入及無新增應用程式請求。Chromium 可能在 Hash 導覽後重新要求既有 favicon，此瀏覽器圖示請求與 fetch／XHR 分開檢查。

**尚未驗證實體 iPhone 的音質、恐龍名是否念對、Safari／主畫面差異。** 本環境無法直接開啟 GitHub Pages 網域；部署結果與 iPhone 實際載入需分別確認。詳細測試說明見 [TESTING.md](TESTING.md)。
